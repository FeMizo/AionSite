# Vista local

Ejecutar desde esta carpeta: node preview.mjs
Abrir http://127.0.0.1:8794/.

Editar content.json para cambiar textos, niveles, imágenes y contacto. Mantener sus claves y JSON válido. Las imágenes admiten rutas relativas o HTTPS. contact.whatsapp permanece vacío hasta validar el teléfono; añadir el número internacional solo después de confirmarlo.

Las fotos externas proceden de Unsplash y son material de muestra, no fotografías del colegio. Tipografías: Archivo y Atkinson Hyperlegible Next desde Google Fonts. La vista necesita conexión para estos recursos.

Sin publicación. La solicitud de visita es una vista previa local: no guarda ni envía datos. No hay panel de edición ni backend. Conservar el aviso de demo mientras el contenido siga siendo provisional.
